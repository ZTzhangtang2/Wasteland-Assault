# 铁幕行动 — 仓库区

> 机密 // 铁幕特遣队 · 第七区

一款第一人称射击游戏。十名敌兵据守集装箱堆场，你只有三分钟。从仓库区到灰蓝街区、灰线城市，在废弃的城郊工业地带完成突袭、清场与生存任务。

---

## 背景设定

铁幕特遣队奉命突入第七区。这里是敌占的集装箱堆场与旧城工业区——锈蚀的货柜、废弃的卡车、缠绕的铁丝网，以及据守其间的敌兵。任务简报只有一句话：**清空区域，三分钟内完成**。

---

## 核心玩法

- **限时清场**：任务模式下，10 名敌兵分布在地图各处，3 分钟内全部消灭即告成功
- **真实弹道与命中反馈**：命中提示、爆头判定、击杀确认、受击方向指示
- **动态交战**：敌人会巡逻、警戒、寻找掩体、包抄、换弹、相互通报位置
- **资源管理**：弹药、护甲、投掷物数量有限，补给需要资金
- **战术小地图**：实时显示敌我位置与朝向，可点击放大为全屏战术图，支持缩放与平移

---

## 游戏模式

| 模式 | 说明 |
| --- | --- |
| **突袭（单人）** | 10 名敌兵 · 3 分钟 · 初始步枪 + 手枪 + 手雷 |
| **波次生存** | 无尽波次 · 开局仅一把手枪 · 枪械与投掷物需在补给站购买，敌人逐波增强 |
| **多人 · 合作强袭** | 2–5 人协同清场，队友倒地可救援 |
| **多人 · 1v1 死斗** | 15 杀或 5 分钟 · 四把枪全解锁 · 无限弹药 |
| **多人 · 波次生存** | 最多 5 人协同防守，共享波次进度 |

多人房间通过房间码或邀请链接加入，房主选定地图与模式，队友自动进入同一战场。

## 武器与装备

**枪械**

- **M4 卡宾枪** — 30 发全自动，中距离主力，可切换半自动
- **KS-12 泵动霰弹枪** — 8 发弹鼓，近距离统治力
- **P-9 手枪** — 15 发半自动，轻便可靠
- **SR-7 长弓** — 5 发栓动狙击，开镜后进入瞄准镜视野，可屏息稳定

**投掷物**

- **破片手雷** — 3.6 秒引信，可掐雷控制引爆时机，范围 6.4 米
- **震爆弹** — 2.6 秒引信，致盲敌人并造成耳鸣与白屏，范围 15 米

**其他**

- 护甲升级（三级，逐级提升减伤与护甲上限）
- 医疗包、弹药箱
- 合作模式下的复活币

## 地图

| 地图 | 特征 |
| --- | --- |
| **仓库区** | 集装箱堆场与吊车平台，视距短、转角多，遭遇战为主 |
| **灰蓝街区** | 完整城市路网、地下隧道与狙击塔，中远距离交火，适合架枪推进；支持昼夜时间调节 |
| **灰线城市** | 高密度楼群与高架步道，巷战与立体穿插，掩体密集 |

## 移动与操作

冲刺、跳跃、二段跳、翻越障碍、蹲伏、滑铲、屏息瞄准——完整的移动体系支持立体交战与快速转移。

**桌面端**：WASD 移动 · 鼠标视角 · 左键开火 · 右键开镜 · Shift 冲刺/屏息 · 空格跳跃/翻越 · Ctrl 蹲伏 · C 滑铲 · R 换弹 · 1/2/3 切换槽位 · G 投掷 · B 补给 · Tab 背包 · M 地图

**触屏端**：左侧浮动摇杆移动 · 右侧拖动视角 · 可自定义按键位置与大小，支持陀螺仪辅助瞄准与开火即开镜

---

## 界面与反馈

- 生命 / 护甲条、弹药计数、武器槽位、击杀播报、队伍通讯字幕
- 命中标记与爆头确认、受击方向弧线、低血量脉冲、屏幕震动
- 狙击镜专用准星（含密位刻度）、开镜时自动隐藏十字准星
- 战后结算：消灭数、爆头数、命中率、存活时间与本局收益

---

## 补给与背包

战斗中可随时打开战地补给站，用本局资金购买治疗、护甲、弹药、枪械与投掷物。背包内可配置两个枪械快捷槽与一个投掷物槽，只有放进槽位的武器才能在战场上切换使用。

---

## 设置项

- 视角灵敏度
- 开火立即开镜
- 陀螺仪辅助瞄准（水平 / 垂直轴独立开关与灵敏度、方向反转）
- 触屏按键大小与位置自定义
- 地图专属画质（阴影精度、渲染质量、昼夜时间）
